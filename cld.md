## Памятка

**Что теперь умеет сервер**
- **Безопасность:** вход только по ключу, пароли отключены. Firewall ufw пропускает только SSH, сайты (80/443) и VPN (56117, 2058, 41846). fail2ban блокирует подбор паролей. Обновления безопасности ставятся автоматически.
- **Рабочая папка:** `/home/claude/projects`. В ней лежит [CLAUDE.md](projects/CLAUDE.md) с информацией о тебе, и я читаю его при каждом запуске.
- **Резервная копия:** каждый день в 03:30 UTC (06:30 по Москве) в `/var/backups/projects/`, хранятся 14 последних. Сделать копию вручную: `systemctl start backup-projects`.
- **Как восстановиться из копии:**
  ```
  ls -lt /var/backups/projects/                          # выбрать архив
  mkdir /tmp/restore && tar -xzf /var/backups/projects/projects-ДАТА.tar.gz -C /tmp/restore
  ```
  Нужные файлы потом берёшь из `/tmp/restore/projects/`. Сначала распаковываем в отдельную папку, чтобы случайно не затереть текущие файлы. Можешь просто попросить меня: «восстанови файл X из копии за вчера».

**Если я перестал отвечать**
1. Проверь интернет. Потом в VS Code: `Ctrl+Shift+P` → **Developer: Reload Window**, или переподключись к серверу.
2. Если не помогло, открой новый чат с Claude. Всё важное о тебе он узнает из `CLAUDE.md`.
3. Для длинных задач, которые должны идти без тебя, запускай меня в терминале внутри `tmux`: команда `tmux new -s claude`, затем `claude`. Если связь оборвётся, работа продолжится. Вернуться к ней: `ssh` на сервер и `tmux attach -t claude`.
